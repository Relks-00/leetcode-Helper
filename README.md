# Leetcode Helper for Obsidian

Obsidian LeetCode Workspace — Modern Minimal Edition featuring:
- **4-Quadrant Problem Solving**: Structured approach to tackling coding challenges.
- **Socratic AI Copilot**: Guided questioning and hints powered by LLMs.
- **Code Runner**: Integrated execution environment for your solutions.
- **Architecture Whiteboard**: Visual canvas for algorithmic design and tracing.

## Installation

1. Copy `main.js`, `manifest.json`, and `styles.css` into your vault's plugin directory: `<vault>/.obsidian/plugins/leetcode-helper/`
2. Reload Obsidian.
3. Enable **Leetcode Helper** in **Settings > Community plugins**.

## Configuration

Configure your API key and preferred model in the plugin settings to enable AI Copilot features.
