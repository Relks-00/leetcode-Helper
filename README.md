⚡️ LeetCode Helper
An all-in-one algorithmic practice workspace for Obsidian.

LeetCode Helper transforms your Obsidian vault into a fully integrated coding environment. Stop context-switching between your browser, IDE, and notes. Fetch problems, write code, run test cases, diagram architectures, and get Socratic AI hints—all without ever leaving your vault.

✨ Core Features
Direct Problem Sync: Enter a LeetCode problem ID to instantly fetch the description, constraints, and default test cases straight into your workspace.

Socratic AI Copilot: A built-in AI tutor engineered to guide you, not give you the answer. Get data structure hints, edge case analysis, and step-by-step dry runs.

Bring Your Own Key (BYOK): Full flexibility to use any AI provider. Configure your API key, Base URL, and Model ID in the settings to connect to OpenAI, OpenRouter, Groq, Google Gemini, or even local offline models like Ollama.

Integrated Code Environment: Write, auto-save, and execute your solutions inside an embedded code editor with full syntax highlighting.

Visual Architecture Integration: Utilize Obsidian's native Canvas API to diagram node architectures, map out linked lists, and visualize complex data structures side-by-side with your code.

🚀 Getting Started
1. Installation
(Note: Once approved, you will be able to install this directly from the Obsidian Community Plugins tab).

Download the latest release from the repository.

Extract the folder into your vault's .obsidian/plugins/ directory.

Open Obsidian, navigate to Settings > Community plugins, and toggle LeetCode Helper on.

2. Configuration
To enable the Socratic Copilot, you must configure your AI provider:

Go to Settings > LeetCode Helper in Obsidian.

Enter your API Key.

Set your Base URL (e.g., [https://api.openai.com/v1](https://api.openai.com/v1), [https://generativelanguage.googleapis.com/v1beta/openai](https://generativelanguage.googleapis.com/v1beta/openai) for Gemini, or http://localhost:11434/v1 for local models).

Specify the Model ID (e.g., gpt-4o-mini, gemini-2.5-flash, llama3).

3. Usage
Open the LeetCode Workspace via the ribbon icon or command palette.

Type a problem number into the input field at the top of the workspace and click Fetch Data.

Write your solution in the bottom-left editor panel.

Use the Socratic Copilot chat window on the right to ask for hints, complexity analysis, or debugging help.
